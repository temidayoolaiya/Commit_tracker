# commit_tracker
# My Git commit Tracker
# This shows the daily contribution and flags the drops compared to the last time it was recorded.

# SETUP
 1. pip install requests 
 2. Create a token(classic, NO scopes needed - it only reads public data):
        https://github.com/settings/tokens
 3. Setu env variables: 
    export GH_Username = "your-github-username"
    export GH_Token = "ghp_xxxxxx"
 4. Run: python commit_tracker.py
